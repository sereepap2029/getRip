# Avatar Client

This folder will contain the Unity project. Create the Unity project directly here so `Assets/`, `Packages/`, and `ProjectSettings/` remain under `apps/avatar-client/`.

Project-owned scripts belong in `Assets/GetRip/Scripts/`. Keep `MonoBehaviour` classes focused on Unity lifecycle and presentation, and keep service calls behind a typed client interface.

No OpenAI API key or direct OpenAI integration belongs in this application.
